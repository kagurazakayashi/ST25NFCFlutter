## 0.1.0

* Android: Full ST25 NFC support with ST25SDK (40+ ST25 product IDs)
* Android: FTM (Fast Transfer Mode) data send/receive with progress callbacks
* Android: NDEF text record read/write with language code extraction
* Android: Continuous tag discovery via reader mode
* iOS: CoreNFC integration with NFCNDEFReaderSession and NFCTagReaderSession
* iOS: NDEF message detection and tag discovery events
* iOS: FTM operation infrastructure with progress reporting
* iOS: Toast message stream for NFC status events
* Unified Dart API with platform interface and method channel implementation
